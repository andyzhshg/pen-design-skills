# Pen Page：页面构建

使用 `$pen-page` frontier 运行 `$pen-design-core`。

负责 `.pen` 中的一个页面或有边界的 flow。实质写入前确认 audience、primary job、真实 content、states、responsive targets、visual direction、复用 components、保留约束和完成证据。

使用已有 variables 与 components 组装页面。缺少的一次性结构可在页面内创建；复用组件工作转给 `$pen-component`，广泛系统决定转给 `$pen-system`。如果交付物是可抛弃代码而不是 `.pen`，使用项目的 `prototype` Skill。

页面属于重要功能、跨越多个会话或项目要求 design brief 时，保存 design contract。

完成条件：已确认 states 与 responsive targets 已呈现；结构检查通过；聚焦 screenshots 表达了预期层级和 primary action。
