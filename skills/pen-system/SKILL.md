# Pen System：设计标准

使用 `$pen-system` frontier 运行 `$pen-design-core`。

负责共享 foundations：semantic variables、themes、组件政策、命名、code mappings 和长期设计决定。优先服从已有代码或设计 source of truth；创建资产前先解决冲突。

只实现本轮确认的系统范围，不扩张为完整产品页面。组件实现成为主要工作时，转交 `$pen-component`。

完成条件：已确认的 foundations 存在，消费者能够引用它们；长期决定已保存到项目选定的设计文档位置；结构检查在确认范围内没有未解决冲突。
